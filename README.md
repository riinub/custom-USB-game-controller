# Custom-USB-game-controller
I made this as a semester project- Data and Logic Design.
This is an arduino based controller that uses python script as a bridge to communicate between analog signals of the joysticks.
# Hardware used
- Arduino Mega 2560
- 5-pin analog joystiks (2)
- 4 push buttons
- jumper wires
- bread board
- USB 2.0 Cable Type A/B
# Software & Libraries
- Arduino IDE
- Joystick Library for arduino
- Python & IDE
# Issues and Learning
This controller was initially to be made with an arduino pro micro but the microcontroller faced a hardware issue with no enough time to figure it out to I had to switch the approach to AT Mega, which requires a bridge to communicate the analog signals directly with the processor.
